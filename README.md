# Basic Network Sniffer

A basic network sniffer built with Python and Scapy.

## Description

This project captures and displays basic network packet information such as source IP, destination IP, protocol, and packet details.

## Tools & Technologies

- Python
- Scapy
- CSV

## Features

- Captures network packets
- Displays source and destination IP addresses
- Identifies network protocols
- Saves captured information in CSV format

## How to Run

1. Install Python.
2. Install Scapy using:
   pip install scapy
3. Run the program:
   python sniffer.py

## Project Purpose

This project was developed as a basic introduction to network packet capturing and analysis using Python and Scapy.
